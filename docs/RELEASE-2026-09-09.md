# Lila canonical release

Date: 2026-09-09

This release is the maintainable source tree for Lila. It includes the modular FastAPI/PostgreSQL application, Alembic migrations through `0007_preserve_expense_lifecycle`, the legacy Supabase dry-run importer, the PWA frontend, and the presentation-only mobile preview.

The release does not include real credentials, a raw data export, or the legacy ZIP archive. The legacy app remains available in the parent project as read-only reference material.

Validation completed:

- 7 backend tests passed.
- JavaScript and Python syntax checks passed.
- Alembic has one head: `0007_preserve_expense_lifecycle`.
- The mobile preview was checked at 375px wide.
- Legacy dry run mapped 9 tenants, 111 transactions, 3 expenses, 3 archives, and 2 settings with no blocking issues.

The PostgreSQL import is intentionally not run by this release. It requires a real target database and workspace UUID, followed by backup/restore and two-device acceptance testing.
